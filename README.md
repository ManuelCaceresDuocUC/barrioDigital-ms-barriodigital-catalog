# Proyecto: BarrioDigital - Servicio de Catálogo

**Componente:** Microservicio de Dominio (Catálogo)
**Integrantes:** Manuel Cáceres Marín

## Descripción
Microservicio encargado de la administración maestra de los tipos de trámites y la disponibilidad operativa. Permite realizar un CRUD de las categorías de solicitudes, definir sus requisitos y, lo más importante, gestionar y descontar los cupos diarios disponibles a medida que se admiten nuevos trámites en la comuna.

## Tecnologías a usar
* **Framework:** Spring Boot (Java)
* **Base de Datos:** Oracle
* **Integración:** API REST
